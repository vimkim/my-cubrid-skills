# CUBRID Code Analysis Report

This context defines the language for turning one CUBRID source topic into an evidence-backed learning artifact and verified mastery session.

## Language

**Analysis Topic**:
The one primary CUBRID subsystem or mechanism investigated by a Report Run.
_Avoid_: Subject, feature list

**Declared Scope**:
The explicit behaviors, Interfaces, dependencies, and compatibility promises that the Book must reconstruct.
_Avoid_: Whole codebase, general area

**Report Run**:
One provenance-pinned execution of research, experiments, Book creation, Quizzes, audit, and Live Grill for an Analysis Topic.
_Avoid_: Report generation when referring to the complete workflow

**Book**:
The offline Korean HTML artifact that explains the Analysis Topic and its PostgreSQL/MySQL comparison within the Declared Scope.
_Avoid_: Report when referring only to the HTML files

**Claim**:
One substantive, stable-ID statement in the Book that is traceable to Evidence and carries an explicit confidence class.
_Avoid_: Fact unless direct evidence proves it

**Evidence**:
Pinned source, reproducible runtime observation, normative documentation, or test material that supports or limits a Claim.
_Avoid_: Agent consensus, plausible explanation

**Coverage Obligation**:
One mandatory mechanism question that the Book must answer or mark `not-applicable` with Evidence.
_Avoid_: Suggested section

**Experiment**:
A captured CUBRID-only runtime procedure that tests a named hypothesis and separates observation from interpretation.
_Avoid_: Ad hoc command

**Quiz**:
A static, reproducible Korean learning exercise with a separate Korean answer and CUBRID-only runnable artifact.
_Avoid_: Live question, trivia

**Live Grill**:
The adaptive Korean conversation that asks one question at a time and requires learner teach-back across all mastery areas.
_Avoid_: Quiz, report review

**Completeness Audit**:
An independent adversarial review of the Book, Evidence, Experiments, and Quizzes against every Coverage Obligation.
_Avoid_: Live Grill, spell check

**Readiness Declaration**:
The Book's bounded conclusion about whether its Declared Scope is sufficient for conceptual and behavioral reimplementation.
_Avoid_: Drop-in compatibility claim

**Mastery**:
The learner's demonstrated ability to explain the mechanism, invariants, failures, trade-offs, and database differences without being shown the answer first.
_Avoid_: Reading completion, quiz availability
